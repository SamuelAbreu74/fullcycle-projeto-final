# Uso de IA

Este projeto foi desenvolvido com assistência de IA sob direção e revisão do responsável pelo projeto.

## Prompts relevantes

- Solicitação para atuar como mentor técnico e desenvolver um Projeto B simples, com API de domínio único, sem microsserviços ou funcionalidades fora dos requisitos.
- Instrução para apresentar ideias e planejamento antes de implementar, trabalhar em etapas e aguardar aprovação.
- Escolha aprovada: controle de despesas pessoais.
- Aprovação do planejamento técnico com TypeScript, Fastify, SQLite, Vitest, Repository, Docker Compose, GitHub Actions, OpenAPI e k6.
- Instruções para justificar decisões, testar comportamentos reais, documentar resultados medidos e não inventar métricas.

Os testes automatizados e a medição de desempenho foram executados durante o desenvolvimento. A IA não substitui a revisão final, a compreensão do código nem a responsabilidade do autor pela entrega.
